## Vita32 ⌚

**An ESP32-based Smartwatch**

Vita32 is a compact, WiFi-enabled smartwatch built around the ESP32. It combines essential daily utilities with connected features, all navigated through a touch interface and a physical potentiometer for intuitive control.
